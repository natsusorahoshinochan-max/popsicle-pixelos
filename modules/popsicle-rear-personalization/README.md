# popsicle 背屏美化

目标基线：20261007 四项修复 PixelOS ROM。入口：**设置 → 显示 → 背屏**。

当前交付 v0.2 已编译通过，并于 2026-10-14 获用户确认“测试已通过”。

功能为单张图片（预览、移动与缩放裁剪）、单段静音循环视频、背屏常亮和长按进入壁纸/样式编辑开关。素材保存到 SSC 自有目录。常亮依赖 NonUI_Back 的实际读数；口袋传感器缺失时不允许开启，未取得读数时不保持屏幕常亮。关闭常亮释放本功能的电源要求。

模块仅覆盖 Settings、PopsicleSubscreenCenter 及其预优化文件，使用 KernelSU 标准 system 挂载目录。v0.2 支持直接覆盖已交付的 v0.1；其它同路径覆盖模块须先停用并重启。不匹配基线或已知版本 APK 时安装会退出。已撤回的背屏完整 ROM 不属于支持基线。

安装后重启；从 v0.1 升级后重新选择并应用图片或视频，使内容使用修正后的发布参数与视频模板。旧素材仅在 SSC 下次启动时按持久化配置引用回收，当前进程内保留以免切换期间误删。

停用或卸载模块并重启恢复 ROM 原 APK；自选素材仍保存在 SSC 数据目录，需要清除自选内容时先在配置页选择“恢复系统原有内容”。

源码与构建记录见 [背屏美化](../../docs/pixelos/validation.md)。构建和打包脚本使用现有 Android 输出及原始 target-files，不操作手机。
