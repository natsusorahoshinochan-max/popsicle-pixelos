# 背屏素材与编辑控制

当前入口为设置 → 显示 → 背屏。支持单图、单段静音循环视频、背屏常亮和长按编辑开关，
配置及素材按用户保存，重启后恢复。

## 素材与存储

Settings 提供媒体选择、图片裁剪缩放和视频预览，SSC 通过受签名、包名及权限保护的
Provider 接收已打开的文件描述符，自行写入 DE 应用目录。图片与视频沿原 Widget
持久化和刷新入口应用，保留原有内容及相机让位生命周期。

视频使用既有解码和播放能力，单文件最大 256 MiB、最长边 4096 像素。
素材发布等待实际持久化结果，旧素材按持久化引用清理。

## 常亮与长按

常亮只对识别出的内置背屏获取显示组限定 WakeLock，用户切换和关闭功能时释放。
NonUI_Back 读数与口袋保护控制常亮资格，传感器缺失、注册失败或尚未取得读数时保持
对应失败状态。

长按编辑在排队、资格和执行入口共同受开关约束，并同步无障碍长按声明。

生产实现由[背屏适配](../../device/xiaomi/popsicle/oem-rear/adaptation/)和 PixelOS
Settings 接线共同提供。当前正式序列保存实际集成范围。
