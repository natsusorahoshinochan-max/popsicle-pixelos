# PixelOS 已知限制与挂起范围

当前源码与成品状态见[进度](progress.md)。以下范围按具体维护任务处理。

| 范围 | 当前边界 |
|---|---|
| 蜂窝网络 | NR 注册 raw30 适配和官方信号显示阈值已集成，PCC、实际载波聚合信息及 5G+ 仍有未决范围 |
| AICore | 完整签名包和服务装配已接入，模型清单曾返回 `INVALID_ARGUMENT`，推理结果未确认 |
| VPN | 入口过滤所有权已有修复，UID 路由部分失败后的完整恢复仍待处理 |
| Bluetooth | 编码器偏好保留已有修复，provider 首次启动和会话恢复仍有条件性缺口 |
| 充电 | 官方认证、PPS 与上层温控场景存在差异，唯一根因未确认 |
| 颜色与音频 | 已有整包反馈保留，P3/HDR 色度、外接麦克风和全部异步路由场景缺少逐项设备结论 |
| 相机与背屏 | 全镜头、全部扩展尺寸、锁屏取消和所有 CameraOpt 生命周期组合缺少逐项设备结论 |
| 安装 | 保留数据模式的启动与解密兼容性未获单独实机结论 |

Wi-Fi 6 GHz 保留在独立调试范围。官方 Settings、ThemeManager 整套移植保持产品范围外状态。
当前背屏美化由 PixelOS 配置页和既有 SSC 适配承接。

构建和交付结果见[源码发布说明](source-publication.md)，安装按[安装契约](fastboot-install.md)执行。
